# Jarvis frontend

React + Vite starter. The previous 3D orb, renderer shaders, Blender files,
models and generated previews were removed to restart the visual work cleanly.

```sh
npm install
npm run dev
```

The interface connects to the Jarvis backend at `ws://127.0.0.1:8765` by
default. Use the mode button or `?demo=true` to run the local demonstration.
